# שיעורי אמונה — הרב בן ציון אוריאל

https://uriel-emuna.vercel.app — עשר סדרות, 3,196 שיעורים, 1,808 שעות.

| קובץ | תפקיד |
|---|---|
| `pipeline.py` | מוריד מהדרייב, מדחיס ל-48k מונו, מעלה ל-Releases של GitHub |
| `build_episodes.py` | מסדר את ההקלטות לפי מבנה הספר ומפרק את שמות הקבצים |
| `parse_docs.py` | קורא את מסמכי «תוכן השיעורים» (ההדגשה מפרידה כותרת ממיקום) |
| `compose.py` | מרכיב כותרת ותיאור לכל שיעור, מהמקור שבאמת יודע עליו משהו |
| `make_site_data.py` | כותב את קובצי הנתונים שהאתר והפידים קוראים |
| `stats_collect.py` | צילום יומי של מוני ההורדות לכל פרק |
| `site/` | האתר עצמו: עמוד בית, עמוד לכל סדרה, ופיד לכל סדרה |

## מלכודות ששילמנו עליהן

* **release אחד מוגבל ל-1000 קבצים.** לרמב"ם יש 1,227, ו-226 נדחו בשקט עם
  `file_count limited to 1000 assets per release`. מכאן ואילך מפצלים ל-`audio-2`
  ובוחרים יעד לפי מקום פנוי אמיתי — לא לפי חישוב.
* **`pgrep -f` תופס את התהליך ששואל.** שתי פעמים הרגנו כך את ה-shell של עצמנו.
  העצירה יושבת ב-`stop.sh` דווקא כדי שהתבנית לא תופיע בשורת הפקודה של הקורא.
* **הורדה שנכשלת בשקט.** הגרסה הראשונה הורידה מנות של 40 והתעלמה מקוד היציאה.
* **הכוזרי לא כאן.** הוא חי ב-`kuzari-pod.vercel.app` ומחובר לספוטיפיי; האתר
  מצביע עליו ולא משכפל אותו.
